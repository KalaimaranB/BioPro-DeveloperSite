# Admin Workflow Guide: True Root Authority Management

This guide outlines exactly what you (the BioPro Root Admin) need to do to securely manage the True BioPro Root Authority and update the Sub-Authorities registry.

## Security Premise
The private key matching `BIOPRO_ROOT_PUBLIC_KEY_HEX` (hardcoded in the BioPro Core) **must never touch the internet or Supabase**. It should be kept on an encrypted offline drive (e.g., an encrypted USB drive in a safe).

Supabase does NOT manage this key. Supabase simply hosts the resulting signed payload.

---

## Workflow: Adding a New Sub-Authority

When you want to authorize a new Sub-Authority (like the BioPro Portal itself, or a university partner like UBC), you must sign their public key using your Offline Root Key.

### Step 1: Secure the Root Key Offline
1. Ensure your True Root Private Key (`root_private.pem` or `.bin`) is located on your secure offline machine.

### Step 2: Prepare the Authorities Payload
On your offline machine, create a JSON file (e.g., `authorities_raw.json`) containing the Sub-Authorities you want to trust.
This must strictly match the list format expected by `TrustSync.fetch_and_sync_authorities()`.

```json
[
  {
    "name": "BioPro_Portal_Default",
    "public_key": "<The Ed25519 public key hex generated by the Portal>",
    "endpoint": "https://biopro-portal.vercel.app"
  },
  {
    "name": "UBC_Bioinformatics_Lab",
    "public_key": "<UBC's public key hex>",
    "endpoint": "https://ubc.ca/biopro"
  }
]
```

### Step 3: Run the Offline Signing Script
You'll need a simple Python script on your offline machine to canonicalize and sign the JSON array.

```python
import json
from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.primitives.asymmetric import ed25519

# 1. Load your offline Root Private Key
with open("root_private.pem", "rb") as f:
    private_key = serialization.load_pem_private_key(f.read(), password=b"YOUR_SUPER_SECRET_PASSPHRASE")

# 2. Load the authorities data
with open("authorities_raw.json", "r") as f:
    authorities = json.load(f)

# 3. Canonicalize EXACTLY as the Core expects (sort_keys=True)
canonical_bytes = json.dumps(authorities, sort_keys=True).encode("utf-8")

# 4. Sign the payload
signature = private_key.sign(canonical_bytes)

# 5. Output the final signed payload for Supabase
final_payload = {
    "authorities": authorities,
    "signature": signature.hex()
}

with open("authorities_signed.json", "w") as f:
    json.dump(final_payload, f, indent=2)
```

### Step 4: Upload to Supabase Storage
1. Move the generated `authorities_signed.json` from your offline machine to your internet-connected admin machine via a USB drive.
2. Log into the Supabase Dashboard.
3. Go to **Storage**.
4. Open the `registries` bucket.
5. Upload the `authorities_signed.json` file.

The Next.js endpoint (`GET /api/v1/authorities/registry`) will be configured to simply fetch and return this file from the Storage bucket. BioPro Core users will immediately begin downloading the new Sub-Authorities on their next startup!
